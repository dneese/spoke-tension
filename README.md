# SpokeTension

Веб-балансувальник велосипедного колеса за допомогою тензометра. Працює повністю в браузері на GitHub Pages — без сервера.

Жива сторінка: <https://dneese.github.io/spoke-tension/>

## Можливості

- Підтримка тензометрів: **ParkTool TM-1** та **ZTTO TC-02**.
- Таблиці калібрування «показ шкали → натяг (кгс)» для різних діаметрів/профілів спиць; лінійна інтерполяція, клампинг за межами шкали.
- Кількість спиць: 24 / 28 / 32 / 36, окремі колонки введення L/R.
- Радарний графік натягу двох сторін + пунктирні полігони цільового натягу.
- Статистика кожної сторони: середній натяг (кгс), розкид (±%), відхилення від цілі; колірне попередження при виході за допуск.
- Автозбереження в `localStorage`, експорт/імпорт стану в JSON.

## Як використовувати

1. Виберіть тензометр і тип спиці.
2. Вкажіть кількість спиць та цільовий натяг для кожної сторони (кгс).
3. Вводьте показ тензометра для кожної спиці — графік і статистика оновлюються миттєво.
4. Отримайте ключ для майбутньої автоматизації через `window.TensionApp` (наприклад, з Bluetooth-датчиком).

## Локальний запуск

Відкрийте `index.html` у будь-якому браузері. Для графіка потрібен інтернет (Chart.js з CDN jsDelivr).

## Розгортання на GitHub Pages

Репозиторій налаштовано на деплой через GitHub Actions (див. `.github/workflows/deploy.yml`, `actions/configure-pages` → `upload-pages-artifact` → `deploy-pages`). Увімкнено через `Pages → Source: GitHub Actions`.

## Джерела даних калібрування

Таблиці показів узгоджено з відкритим проєктом [wheelbuildchart](https://github.com/KonstantinShemyak/wheelbuildchart) (GPL-3.0, автор Konstantin Shemyak), який наводить посилання на офіційні документи:

- **Park Tool TM-1** — Wheel Tension Measurement (parktool.com)
- **ZTTO TC-02** — таблиця виробника з AliExpress (архівована копія на archive.org)

Це довідкові вимірювальні значення; для максимальної точності звіряйтеся з інструкцією вашого приладу.

## Ліцензія

Код та UI написані з нуля (не форк). Дані калібрування — фактичні вимірювання з відкритих джерел, використовуються з посиланням на авторство.
